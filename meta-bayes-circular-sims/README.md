# Sequential meta-Bayesian inference with continuous circular data — simulations

Simulations accompanying the note *Sequential Meta-Bayesian Inference With Continuous Circular Data* (12 Oct 2026).

**Model.** Three hypotheses with centres μ_k = 0°, 120°, 240° and von Mises likelihood VM(x; μ_k, κ). Angles are embedded as unit vectors, and the belief is the 2D vector η_t = κ Σ e^{ix_s}, with logits log π + Eη_t. Noise is added to η, either at readout or at every step (accumulating). Denoising is a shrinkage problem in ℝ².

## Files

| File | Contents |
|---|---|
| `circbayes.py` | Core model (vectorised NumPy): sampling, belief trajectories, the two noise models, the Gaussian-prior denoiser from the note, the generative model's own mixture-prior denoiser, plug-in and E[softmax] readouts (2D Gauss–Hermite), the full loop with both choice-point options, and metrics |
| `verify.py` | 15 numerical checks of every closed-form claim in the note |
| `experiments.py` | Experiments 1–5 below; writes `figures/` |

## Running

```bash
pip install -r requirements.txt
python verify.py        # ~45 s
python experiments.py   # ~20 min at the default sizes; reduce N for quick runs
```

Seeds are fixed (`default_rng(0)` for verification, `default_rng(2026)` for the experiments).

## Results

All runs use κ = 1 (1.7 in the verification checks), a flat prior and m = 0.

**Verification (15/15 pass).** The checks cover:
- the frame identities Eᵀ E = 3/2·I and E Eᵀ = 3/2·P;
- sequential logits against brute-force Bayes (error about 1e-15);
- the worked example and |S| = 2|cos(Δ/2)|;
- the noise conversion σ² = σ_ℓ²/(3/2);
- the posterior predictive as a three-component VM mixture;
- per-step noise variance tσ²;
- the CLT moments of η_t | k.

The claim that the plug-in readout is overconfident held in 100% of 10⁵ random cases. That is a simulation result, not a proof.

**1. Choice of denoiser** (`fig1_denoisers.png`). Under the model, the true prior on η_t is a three-lobed anisotropic mixture, not N(m, s²I). With that prior, E[softmax(log π + Eη) | η̃] = p(k | η̃) exactly, so the note's q is Bayes-optimal whenever its prior is correct. At σ = 1.5, t = 10:

| Method | KL to noise-free posterior (nats) | Top-label ECE |
|---|---|---|
| raw plug-in | 1.89 | 0.28 |
| Gaussian + plug-in | 0.83 | 0.17 (overconfident) |
| Gaussian + E[softmax] | 0.65 | 0.06 (underconfident) |
| mixture prior (Bayes) | 0.64 | 0.005 |

**2. Which w_t regime holds.** On data generated by the model, s_t² ∝ t^1.95, so under readout-only denoising w_t → 1. The constant-w regime (s² ∝ t) appears only for data with no net direction.

**3. Order effects** (`fig2_order_effects.png`). Readout-only denoising is exactly order-invariant, because η̃_T = η_T + Σε_t and τ_T² depends only on T. The note's claim that per-step noise alone causes order dependence is therefore wrong. Order effects come only from denoise-and-propagate:
- with a Gaussian prior it acts as a leaky integrator, giving **recency** (order effect −0.69 to −0.76 on q₀ − q₁);
- with the mixture prior it settles into whichever hypothesis it reaches first, giving **primacy** (+0.11).

**4. Polarization from internal noise** (`fig3_polarization.png`, `fig4_final_beliefs.png`). Pairs of agents see identical mixed evidence with independent internal noise (σ = 1). Pairs ending in opposite confident camps at t = 40:

| Method | Opposite camps |
|---|---|
| no denoising | 27.7% |
| Gaussian denoisers | 0.4% |
| mixture, readout-only | 8.9% |
| mixture, propagate | 49.4% |

Under mixture-propagate, which camp an agent joins is close to a coin flip relative to its twin. **Caveat:** mixed evidence violates the model's single-source assumption, and mixture-propagate has not been run on correctly specified data.

**5. Normative contrary updating** (no noise). With three hypotheses, exact Bayes can move a shared hypothesis in opposite directions for two agents who see the same datum. The exact rule: p_k rises if and only if e_k·Δη > log E_p[exp(e·Δη)]; to first order, (e_k − ē_p)·Δη > 0. Random agent pairs move H0 in opposite directions 7.4% of the time (cf. Jern, Chang & Kemp, 2014, *Psychological Review*).

## Known limitations

- The mixture denoiser uses a CLT approximation for η_t | k. Against exact Monte Carlo, the mean absolute error in p(k | η̃) is 0.034 at t = 1, 0.018 at t = 3 and 0.002 at t = 10.
- Denoise-and-propagate follows the note's literal loop (τ² = σ² per step, prior re-imposed each step), so it counts the prior more than once. A properly filtered variant is not implemented.
